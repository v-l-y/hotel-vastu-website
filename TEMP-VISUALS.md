# Temporary Representative Visuals

These files are intentionally temporary and must not be treated as photographs of the actual Hotel Vastu Premium property:

- `images/temp/restaurant-temp.svg` — used on `restaurant.html`
- `images/temp/reception-temp.svg` — used on `contact.html`
- `images/temp/exterior-temp.svg` — used on `hotel-near-rps-more.html`

Each visible temporary image carries a **Representative visual** badge through shared CSS.

## Replacement rule

When an original Hotel Vastu Premium photo becomes available:

1. Replace the temporary asset with the verified first-party photo.
2. Convert/optimize it to WebP or AVIF.
3. Update the page image path and alt text.
4. Remove the temporary/representative badge from that image wrapper.
5. Update this file so the replaced asset is no longer listed as temporary.

Do not remove the representative label while the image is illustrative rather than an actual hotel photograph.
